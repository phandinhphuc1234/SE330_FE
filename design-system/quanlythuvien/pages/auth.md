# Auth page override

- Keep authentication tasks inside one focused card with a maximum readable width of 560px.
- Email verification uses a quiet black, white, and neutral-gray palette. Do not copy third-party branding or illustration styles.
- Render one visible box per verification-code digit. The group must support keyboard entry, arrow navigation, Backspace, full-code paste, browser one-time-code autofill, and Enter submission.
- Never ask the user to retype or edit the registered email on the verification page. Read it from the registration session and provide a clear recovery route when that session is unavailable.
- On small screens, all nine digit boxes stay on one row without horizontal scrolling; reduce gaps and box width before wrapping.
- Use strong black focus states, explicit text for errors and success, and a single black primary action.
